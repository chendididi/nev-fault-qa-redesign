## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：BMS / 电池管理系统 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：BMS / 电池管理系统 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - BMS 主控单元（电池包内高压配电区低压侧）
  - 从控采样板 CSC（各电池模组侧，采集单体电压与温度）
  - 霍尔电流传感器或分流器（电池包高压负极回路）
  - 绝缘监测模块 IMD（高压正负极对车身绝缘检测）
- 控制逻辑：BMS / 电池管理系统把单体电压、温度、电流、SOC、SOH、绝缘电阻和继电器状态通过 CAN 发送给 VCU；充电时 BMS 根据电芯状态向 OBC / 车载充电机或直流充电桩发送允许电流和允许电压。
- 常见故障现象：
  - 快充连接成功但 SOC 不上升，充电桩显示已连接或小电流充电。
  - 仪表提示动力电池故障，BMS 数据流单体电压跳变。
  - 车辆续航估算漂移，充电电流显示与实际不一致。

## 第5页 / 第4.1章：P1B10 充电电流有效但 SOC 不上升
- 章节 4.1 / 页码 5 / 系统：BMS / 电池管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1B10
- 故障名称：充电电流有效但 SOC 不上升
- 用户现象：技师自然语言提问：快充时 SOC 不上升但充电桩显示已连接，可能原因有哪些？
- 触发条件：BMS 检测充电电流大于 10A 持续 5 min，但 SOC 增量小于 0.1%，且最高单体电压上升小于 5 mV。
- 可能原因：
  1. 电流传感器方向或零点异常，BMS 误判充放电电流。
  2. BMS SOC 算法未完成校准，历史容量参数异常。
  3. 快充桩只完成连接未输出有效电流，BMS 数据流充电电流为虚假或瞬时值。
  4. 单体电压采样冻结，BMS 未感知真实电压变化。
- 检查步骤：
  1. 确认车辆处于安全充电工位，观察充电桩输出电压、电流和计费电量，记录 5 分钟趋势。
  2. 读取 BMS 数据流：充电允许状态、充电电流、母线电压、最高/最低单体电压、SOC 增量和快充报文计数。
  3. 使用钳形直流电流表夹测电池包高压负极线束外侧，确认实际电流与 BMS 电流数据差值是否小于 5A。
  4. 若实际电流为 0A，转查快充系统握手和充电桩输出；若实际电流正常但 SOC 不变，执行 BMS 容量参数校准。
  5. 断电后检查电流传感器低压连接器，测量 5V 供电、地线压降和信号电压。
- 标准值：BMS 充电电流与钳表差值 ≤5A；电流传感器 5V 供电为 4.8V-5.2V；有效快充时单体电压 5 min 应有可测上升；SOC 10 min 增量应 >0.2%。
- 维修建议：电流传感器零漂时执行零点学习，失败则更换传感器；SOC 参数异常时执行 BMS 标定流程；采样冻结时修复从控 CAN 或采样板。
- 复核方法：连接快充桩充电 10 分钟，确认 BMS 电流、桩端电流、SOC 增量和单体电压趋势一致，清码后再次充电复核。
- 安全提醒：快充测试只能在连接器锁止且无绝缘故障时进行；禁止拆开高压电流传感器外壳或带电调整高压线束。

## 第6页 / 第4.2章：P1B11 单体电压采样线断路或跳变
- 章节 4.2 / 页码 6 / 系统：BMS / 电池管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1B11
- 故障名称：单体电压采样线断路或跳变
- 用户现象：用户现象：仪表提示动力电池故障，诊断仪 BMS 单体电压某一路显示 0V、5V 或随振动跳变。
- 触发条件：任一单体电压低于 1.5V 或高于 4.5V 持续 200 ms，或相邻采样通道电压差瞬时变化超过 300 mV。
- 可能原因：
  1. 采样线束端子退针、压接不良或连接器未锁止。
  2. 从控采样板 CSC 通道损坏。
  3. 电池包维修后采样线顺序错误。
  4. 连接器进水腐蚀导致接触电阻增大。
- 检查步骤：
  1. 断开高压维修开关并确认母线电压低于 30V，拆卸低压采样连接器前佩戴绝缘手套。
  2. 读取异常单体编号，核对对应模组和采样连接器端子号。
  3. 使用高阻抗万用表测量异常采样通道相邻端子电压，正常单体电压应为 3.0V-4.2V。
  4. 轻微晃动采样线束并观察诊断仪数据跳变，跳变通道优先检查端子保持力。
  5. 若端子实测正常但 BMS 数据异常，互换从控采样板验证故障是否随采样板转移。
- 标准值：单体实测电压 3.0V-4.2V；静置相邻单体差通常 <50 mV；采样连接器端子保持力不得松脱；异常跳变不得超过 20 mV。
- 维修建议：端子退针时更换端子并按原线序复位；采样板损坏时更换 CSC 并写入配置；采样线顺序错误时按端子表复排后进行绝缘和电压复核。
- 复核方法：清码后静置 10 分钟并轻拍线束，确认单体电压连续稳定；执行慢充 15 分钟观察无 P1B11 复现。
- 安全提醒：采样线虽然属于低压测量回路，但相邻多针可能叠加高电位，禁止用普通短接线跨接采样端子。

## 第7页 / 第4.3章：P1B12 电流传感器零点漂移
- 章节 4.3 / 页码 7 / 系统：BMS / 电池管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1B12
- 故障名称：电流传感器零点漂移
- 用户现象：用户现象：剩余续航忽高忽低，熄火后 SOC 缓慢变化，诊断仪显示静置电流不为 0A。
- 触发条件：车辆静置、主继电器断开且无充放电请求时，BMS 检测电流值绝对值大于 3A 持续 30 s。
- 可能原因：
  1. 电流传感器 5V 供电波动或地线压降过大。
  2. 传感器磁芯受外部强磁影响或内部零点漂移。
  3. 低压连接器进水，信号线对电源或对地漏电。
  4. BMS 电流采样标定参数丢失。
- 检查步骤：
  1. 车辆下电静置 3 分钟，确认无充电枪连接、无空调和热管理请求。
  2. 读取 BMS 静置电流、12V 电压、传感器供电和传感器温度。
  3. 测量电流传感器低压连接器 5V 供电、地线压降和信号电压；信号线禁止搭铁短试。
  4. 执行 BMS 电流零点学习，学习前确认高压主继电器为 Open。
  5. 学习失败时断电检查线束屏蔽层和连接器是否进水。
- 标准值：静置电流应在 -1A 到 +1A；触发阈值 >3A 持续 30 s；5V 供电 4.8V-5.2V；地线压降 <0.05V。
- 维修建议：供电异常时修复 BMS 低压供电；传感器零点学习失败时更换电流传感器并执行标定；连接器进水时更换端子和密封件。
- 复核方法：车辆静置 10 分钟，确认 BMS 电流稳定在 ±1A 内；慢充和驱动工况下电流方向正确。
- 安全提醒：电流传感器拆装前必须下电并确认高压电缆无残压；禁止改变高压线束穿过传感器的方向。

- 案例1：车辆快充 20 分钟 SOC 仍为 42%，桩端电量增长为 0.1 kWh。读取 BMS 发现充电电流数据固定 18A，但钳表为 0A，快充报文计数中断。最终定位为快充 CAN 屏蔽线进水导致桩端未输出有效电流。
