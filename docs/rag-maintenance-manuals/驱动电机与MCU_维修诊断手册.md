## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：驱动电机与 MCU / 电机控制器 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：驱动电机与 MCU / 电机控制器 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - 驱动电机总成（前/后桥电驱，含三相绕组和温度传感器）
  - MCU / 电机控制器（电驱壳体上方，逆变驱动三相电机）
  - 旋变传感器 Resolver（电机端盖内，反馈转子位置）
  - 电驱冷却水泵、散热器和水温传感器
- 控制逻辑：VCU 根据加速踏板和车辆状态发送扭矩请求给 MCU / 电机控制器，MCU 根据母线电压、IGBT 温度、电机温度和旋变位置控制三相电流；温度过高或冷却不足时 VCU 限扭保护。
- 常见故障现象：
  - 仪表提示动力受限，MCU 温度 95℃，车辆加速无力。
  - 行驶中抖动、异响或报电机相电流不平衡。
  - READY 后挂挡不走，诊断仪显示旋变信号异常。

## 第5页 / 第4.1章：P0A3C MCU 温度 95℃ 限扭 / 冷却不足
- 章节 4.1 / 页码 5 / 系统：驱动电机与 MCU / 电机控制器 / 车型：NEV-A01/NEV-B02
- 故障码：P0A3C
- 故障名称：MCU 温度 95℃ 限扭 / 冷却不足
- 用户现象：技师自然语言提问：电机控制器温度 95℃且车辆限扭，怎么判断水泵故障？
- 触发条件：MCU / 电机控制器 IGBT 温度达到 95℃ 持续 5 s，且冷却泵请求转速大于 60% 时，VCU 进入限扭。
- 可能原因：
  1. 电驱冷却水泵不工作或实际转速低。
  2. 电驱冷却回路有空气、冷却液不足或散热器堵塞。
  3. MCU 温度传感器偏移或线束接触不良。
  4. 长时间高负载行驶后冷却风扇未启动。
- 检查步骤：
  1. 停车下电，检查冷却液液位；热车状态不得打开膨胀壶盖，等待冷却后再补液。
  2. 读取 MCU 温度、电机温度、冷却液入口温度、水泵请求转速、水泵实际转速和风扇状态。
  3. 用诊断仪执行电驱水泵主动测试，听取水泵运转声并观察膨胀壶回流；无回流时继续测水泵供电。
  4. 测量水泵低压连接器供电，启动请求时应为 10.5V-14.5V；LIN/CAN 控制线不得对地短路。
  5. 用红外测温仪比较 MCU 进出水管温差，水泵正常时温差通常为 3℃-10℃，完全无流量时进出水温差异常增大。
  6. 若水泵供电和控制正常但实际转速为 0 rpm，更换水泵；若实际转速正常但温度仍快速上升，检查散热器和排气。
- 标准值：MCU 正常温度 <85℃；95℃ 进入限扭；水泵请求与实际转速偏差 <15%；水泵供电 10.5V-14.5V；冷却液液位在 MIN-MAX 之间。
- 维修建议：水泵不转时先修复供电或通讯，再更换水泵；冷却回路有空气时抽真空加注并排气；散热器堵塞时清洗或更换。
- 复核方法：路试上坡或台架加载 15 分钟，确认 MCU 温度低于 85℃、水泵实际转速跟随请求且车辆不再限扭。
- 安全提醒：电驱冷却系统连接高压部件壳体，拆水管前必须高压下电；禁止在电驱高温时拆卸水管或膨胀壶盖。

## 第6页 / 第4.2章：P0A92 驱动电机三相电流不平衡
- 章节 4.2 / 页码 6 / 系统：驱动电机与 MCU / 电机控制器 / 车型：NEV-A01/NEV-B02
- 故障码：P0A92
- 故障名称：驱动电机三相电流不平衡
- 用户现象：用户现象：低速起步抖动，仪表提示驱动系统故障，清码后一加速故障复现。
- 触发条件：MCU 检测 U/V/W 三相电流差值超过 15A 持续 200 ms，且扭矩请求大于 20 N·m。
- 可能原因：
  1. 三相高压连接器端子松动、烧蚀或接触电阻增大。
  2. 电机绕组局部短路或对壳绝缘下降。
  3. MCU IGBT 某相驱动异常。
  4. 三相电流传感器采样偏移。
- 检查步骤：
  1. 断开高压维修开关，等待 5 分钟并确认母线电压低于 30V 后，拆检三相连接器。
  2. 检查 U/V/W 端子是否烧蚀、退针或进水，测量端子接触电阻。
  3. 使用毫欧表测量三相绕组相间电阻，U-V、V-W、W-U 差异不应超过 5%。
  4. 使用 500V 绝缘电阻表测量每相对电机壳体绝缘，确认高于 1MΩ。
  5. 若电机绕组正常，读取 MCU 三相电流偏置并执行电流传感器校准。
- 标准值：三相绕组电阻差异 ≤5%；每相对壳绝缘 ≥1MΩ；三相端子接触电阻 <0.2 mΩ；空载电流偏置接近 0A。
- 维修建议：端子烧蚀时更换三相线束或电机端连接器；绕组不平衡时更换驱动电机；MCU 某相输出异常时更换 MCU 并复查电机绕组。
- 复核方法：清码后进行低速起步、加速和能量回收测试，确认三相电流波形平衡且无 P0A92。
- 安全提醒：三相线束属于高压大电流回路，必须确认残压低于 30V 后拆卸；禁止用普通万用表短接测相间阻值。

## 第7页 / 第4.3章：P0C73 旋变 Resolver 信号异常
- 章节 4.3 / 页码 7 / 系统：驱动电机与 MCU / 电机控制器 / 车型：NEV-A01/NEV-B02
- 故障码：P0C73
- 故障名称：旋变 Resolver 信号异常
- 用户现象：用户现象：车辆 READY 后挂挡不走或偶发报驱动系统故障，重新上电后短暂恢复。
- 触发条件：MCU 检测旋变正余弦信号幅值低于 0.5V 或相位不合理持续 100 ms。
- 可能原因：
  1. 旋变低压连接器松动、进水或屏蔽线断开。
  2. 旋变线束靠近高压三相线导致干扰。
  3. 旋变传感器内部开路或短路。
  4. MCU 旋变激励输出异常。
- 检查步骤：
  1. 读取 MCU 数据流：转子角度、旋变幅值、激励电压和故障发生转速。
  2. 断电后检查旋变连接器锁止和屏蔽层接地，确认线束未与三相高压线束捆扎过紧。
  3. 测量旋变激励线圈和正余弦线圈电阻，三组阻值应符合端子表范围且无对地短路。
  4. 使用示波器在低压侧观察旋变信号，转动电机时正弦和余弦波形应连续无断点。
  5. 若线束与传感器正常，检查 MCU 激励输出。
- 标准值：旋变信号幅值通常 >0.5V；线圈对地绝缘 >1MΩ；屏蔽层接地电阻 <0.1Ω；角度变化应连续无跳变。
- 维修建议：连接器进水时更换端子和密封件；线束屏蔽损坏时更换旋变线束；传感器开路时更换电机端盖旋变组件或电机总成。
- 复核方法：清码后执行前进/倒车切换和低速行驶 5 km，确认转子角度连续且无 P0C73。
- 安全提醒：旋变排查在低压侧完成，但靠近电机高压端子时仍需高压下电；禁止带电拆 MCU 插头。
