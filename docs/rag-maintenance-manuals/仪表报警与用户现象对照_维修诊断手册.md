## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - 组合仪表 IPC（驾驶员前方，显示 READY、故障灯和文本报警）
  - VCU / 整车控制器（汇总高压、充电、驱动和热管理故障）
  - 诊断网关与 OBD 接口（读取 DTC 和冻结帧）
  - BMS、MCU、OBC、DC/DC 等报警源控制器
- 控制逻辑：仪表报警不是根因，IPC 根据 VCU 和各控制器发送的状态显示“高压系统故障”“充电系统故障”“动力受限”等文本。维修时必须把用户现象、仪表文字、DTC 和数据流绑定定位。
- 常见故障现象：
  - 仪表显示高压系统故障，车辆无法 READY。
  - 仪表显示充电系统故障，快充或慢充无法启动。
  - 仪表显示动力受限，车辆能行驶但加速无力。

## 第5页 / 第4.1章：B1001 仪表显示高压系统故障
- 章节 4.1 / 页码 5 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02
- 故障码：B1001
- 故障名称：仪表显示高压系统故障
- 用户现象：用户现象：车辆无法 READY，但 12V 静态电压 12.6V，仪表显示高压系统故障。
- 触发条件：IPC 接收到 VCU 高压系统故障标志，或 BMS 上报禁止 READY 状态持续 1 s。
- 可能原因：
  1. BMS 预充失败、主继电器未闭合或 HVIL 开路。
  2. 绝缘电阻低于阈值，BMS 禁止上高压。
  3. VCU 与 BMS 通讯丢失，仪表采用降级报警。
  4. 12V 供电负载下跌落导致控制器重启。
- 检查步骤：
  1. 记录仪表文字和故障灯状态，确认 READY 指示是否点亮。
  2. 执行全车扫描，优先查看 BMS、VCU 和网关当前 DTC，不以 B1001 单独判定根因。
  3. 读取 BMS 数据流：HVIL 状态、绝缘电阻、预充状态、主继电器状态和母线电压。
  4. 若 12V 静态为 12.6V，继续做负载测试和 VCU/BMS 供电压降测试。
  5. 根据当前 DTC 转入 P0A0F、P0AA6、U0121 或低压唤醒流程。
- 标准值：READY 请求后 BMS 应输出预充状态；HVIL Closed；绝缘 ≥500kΩ；低压负载电压 ≥10.5V；母线残压断电后 <30V。
- 维修建议：按根因修复 HVIL、绝缘、预充或通讯故障；仪表本体只在报警源数据正常但显示异常时考虑更换。
- 复核方法：清码后 READY 上电 3 次，确认仪表无高压系统故障提示，BMS 与 VCU 无当前故障。
- 安全提醒：仪表报警涉及高压系统时，任何拆检高压部件前都要执行下电和残压确认。

## 第6页 / 第4.2章：B1002 仪表显示充电系统故障
- 章节 4.2 / 页码 6 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02
- 故障码：B1002
- 故障名称：仪表显示充电系统故障
- 用户现象：用户现象：插枪后仪表提示充电系统故障，充电桩显示握手失败或慢充无电流。
- 触发条件：VCU 收到 BMS、OBC 或快充系统充电禁止标志，IPC 显示充电系统故障。
- 可能原因：
  1. P1A0C 快充互锁异常或快充电子锁未锁止。
  2. OBC 交流输入、CP/CC 信号或慢充座异常。
  3. BMS 因电池温度、SOC 或绝缘原因禁止充电。
  4. 充电 CAN 通讯超时或桩端兼容性问题。
- 检查步骤：
  1. 区分快充还是慢充失败，记录充电设备提示文本和仪表报警。
  2. 读取 BMS 充电允许、OBC 状态、快充互锁、电子锁、CP/CC 和充电 CAN 报文计数。
  3. 快充失败时优先查 P1A0C、U0111 和快充端子温度；慢充失败时优先查 P1A11、P1C01。
  4. 检查充电口进水、端子烧蚀和锁止动作，必要时使用已知正常充电设备交叉验证。
  5. 确认绝缘电阻和电池温度在允许范围内。
- 标准值：快充 HVIL <1Ω；OBC CP 占空比 10%-96%；BMS 充电允许为 Yes；绝缘 ≥500kΩ；端子温升 <20℃。
- 维修建议：按具体 DTC 修复快充座、慢充座、OBC、BMS 禁止原因或充电 CAN 线束；不要只清除仪表报警交车。
- 复核方法：分别进行快充握手和慢充 10 分钟测试，确认仪表不再显示充电系统故障。
- 安全提醒：充电系统报警时必须先拔枪并下电再拆检充电口或 OBC 高压连接器。

## 第7页 / 第4.3章：B1003 仪表显示动力受限
- 章节 4.3 / 页码 7 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02
- 故障码：B1003
- 故障名称：仪表显示动力受限
- 用户现象：用户现象：车辆能行驶但加速无力，仪表提示动力受限，空调或快充后更明显。
- 触发条件：VCU 接收到 MCU、BMS 或热管理系统限功率标志，仪表显示动力受限。
- 可能原因：
  1. MCU 温度达到 95℃ 或电机温度过高。
  2. 电池温度过高、过低或 SOC 过低导致放电功率限制。
  3. DC/DC 输出异常引起低压系统保护。
  4. 驱动电机三相电流不平衡或旋变异常。
- 检查步骤：
  1. 读取 VCU 限功率原因，区分电池限功率、MCU 限扭还是低压保护。
  2. 检查 MCU 温度、电池最高/最低温度、SOC、BMS 可用放电功率和 DC/DC 输出电压。
  3. 若 MCU 温度 95℃，执行电驱水泵和风扇主动测试。
  4. 若 BMS 可用放电功率低，检查电池温度、单体压差和 SOC。
  5. 若 12V 低，转入 DC/DC P1C02 或低压供电流程。
- 标准值：MCU <85℃ 不应限扭；95℃ 进入保护；READY 后 12V 13.5V-14.8V；单体压差通常 <50 mV；BMS 可用放电功率应与 SOC/温度匹配。
- 维修建议：按限功率来源修复热管理、电池一致性、DC/DC 或驱动系统；仪表报警本身不作为更换仪表依据。
- 复核方法：清码后复现原工况路试，确认 VCU 限功率标志为 No，仪表不再提示动力受限。
- 安全提醒：动力受限可能由高压过温或绝缘保护触发，不得强行解除限扭进行长距离路试。

## 第8页 / 最后章节：典型案例与FAQ
- 章节 5.0 / 页码 8 / 系统：仪表报警与用户现象 / 车型：NEV-A01/NEV-B02。
- 案例1：客户描述“所有灯都亮”，实际仪表主报警为高压系统故障。全车扫描发现 U0121，BMS 常电保险虚接，12V 静态 12.6V 但 BMS 供电为 0V。更换保险座端子后 READY 正常。
- FAQ1：仪表文本只能作为入口，必须读取源控制器 DTC 和数据流。高压系统故障优先看 BMS/VCU，充电系统故障优先看 BMS/OBC/快充 CAN，动力受限优先看 VCU 限功率原因。
- FAQ2：资料不足时如何回答？若检索片段未包含 DTC、数据流或标准值，应提示技师补充诊断仪当前故障码、冻结帧、12V 负载电压、绝缘电阻、充电状态或 CAN 波形，不得编造未引用的维修结论。
