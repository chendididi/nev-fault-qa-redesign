## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：典型维修案例库 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第5页 / 第4.1章：P1A0C 案例：快充互锁异常导致握手失败
- 章节 4.1 / 页码 5 / 系统：典型维修案例库 / 车型：NEV-A01/NEV-B02
- 故障码：P1A0C
- 故障名称：案例：快充互锁异常导致握手失败
- 用户现象：客户抱怨：车辆在公共快充站无法充电，仪表提示充电系统故障，桩端显示握手失败。
- 触发条件：快充枪连接有效，VCU 快充互锁输入低于 2.5V 持续 500 ms。
- 可能原因：
  1. 快充口进水，微动开关端子绿蚀。
  2. 快充 HVIL 低压端子退针。
  3. 电子锁未完全锁止导致互锁状态不闭合。
  4. VCU 互锁输入线束对地短路。
- 检查步骤：
  1. 拔枪下电，断开高压维修开关并确认母线低于 30V。
  2. 读取 VCU 当前 DTC 为 P1A0C，数据流显示快充枪连接 Yes、快充互锁 Open。
  3. 检查快充座排水孔堵塞，低压连接器有水迹。
  4. 测量 X21-3 至 X21-4 插枪锁止电阻为 18 Ω，标准应小于 1 Ω。
  5. 更换快充座并清理排水通道后复测互锁电阻 0.3 Ω。
- 标准值：快充 HVIL 闭合电阻 <1 Ω；VCU 互锁输入 4.5V-5.2V；母线残压 <30V 后才可拆检。
- 维修建议：更换快充座总成，修复线束密封，清理排水孔并做端子防水复核。
- 复核方法：同一快充桩和另一快充桩各握手 3 次，均进入输出阶段，P1A0C 未复现。
- 安全提醒：充电口进水故障不得反复插枪试充；必须拔枪、下电并确认残压后拆检。

## 第6页 / 第4.2章：P0A0F 案例：无法 READY 但 12V 电压 12.6V
- 章节 4.2 / 页码 6 / 系统：典型维修案例库 / 车型：NEV-A01/NEV-B02
- 故障码：P0A0F
- 故障名称：案例：无法 READY 但 12V 电压 12.6V
- 用户现象：客户抱怨：车辆停放后无法 READY，救援人员测 12V 为 12.6V，仪表显示高压系统故障。
- 触发条件：READY 请求后预充未完成，BMS 未允许主继电器闭合。
- 可能原因：
  1. MSD 二次锁止未扣合，HVIL 间歇开路。
  2. BMS 低压供电在负载下跌落。
  3. 预充继电器或预充电阻异常。
  4. VCU 与 BMS 通讯丢失导致 READY 条件不满足。
- 检查步骤：
  1. 读取 DTC：BMS P0A0F，VCU 无法 READY 条件为 HVIL Open。
  2. 下电后检查 MSD，发现二次锁止未完全扣合。
  3. 测量 MSD 互锁端子，轻晃时电阻从 0.4 Ω 跳到开路。
  4. 重新锁止 MSD 后读取 BMS 数据流，HVIL 状态稳定 Closed。
  5. 执行 READY 上电，预充 1.1 s 完成，母线达到电池总压 94%。
- 标准值：MSD 互锁闭合电阻 <1 Ω；预充完成时间 <2 s；母线残压下电后 <30V；12V 负载电压 ≥10.5V。
- 维修建议：正确复位 MSD 并更换磨损锁扣，清码后对客户说明维修开关不得自行拆动。
- 复核方法：连续 READY 上电 5 次和路试 10 km，仪表无高压故障，P0A0F 不复现。
- 安全提醒：无法 READY 不代表高压无电，任何拆检前仍需按高压断电流程确认残压。

## 第7页 / 第4.3章：P0A3C 案例：MCU 95℃ 限扭由电驱水泵失效引起
- 章节 4.3 / 页码 7 / 系统：典型维修案例库 / 车型：NEV-A01/NEV-B02
- 故障码：P0A3C
- 故障名称：案例：MCU 95℃ 限扭由电驱水泵失效引起
- 用户现象：客户抱怨：高速行驶后动力明显下降，仪表显示动力受限，停车冷却后恢复。
- 触发条件：MCU 温度 95℃，电驱水泵请求 80%，实际转速 0 rpm。
- 可能原因：
  1. 电驱水泵内部卡滞。
  2. 水泵供电保险熔断。
  3. 冷却回路有空气导致实际流量不足。
  4. 散热器堵塞或风扇不转。
- 检查步骤：
  1. 读取 VCU 限扭原因为 MCU 过温，MCU 温度峰值 97℃。
  2. 执行水泵主动测试，听不到水泵声音，膨胀壶无回流。
  3. 测量水泵供电 13.8V，控制线波形正常，实际转速仍为 0 rpm。
  4. 断电后更换电驱水泵，抽真空加注冷却液并排气。
  5. 路试同等工况，MCU 温度最高 74℃。
- 标准值：MCU 正常 <85℃；95℃ 限扭；水泵供电 10.5V-14.5V；请求与实际转速偏差 <15%。
- 维修建议：更换电驱水泵，按规定加注冷却液并执行排气；同步检查风扇和散热器。
- 复核方法：路试 15 km，确认动力受限不再出现，P0A3C 清除后未复现。
- 安全提醒：更换水泵前必须下电，热车时等待冷却液降温，避免烫伤和高压部件误触。
