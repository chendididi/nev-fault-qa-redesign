## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - 电池冷却回路（水泵、冷却板、膨胀壶和冷却液温度传感器）
  - 电驱冷却回路（MCU、电机、散热器、电子风扇和电驱水泵）
  - 热泵空调、PTC 高压加热器和电子水阀
  - 热管理控制器或 VCU 热管理功能模块
- 控制逻辑：热管理系统根据电池温度、MCU 温度、环境温度和充电状态控制水泵、风扇、电子水阀、压缩机和 PTC；温度过高会限制充电电流或驱动扭矩。
- 常见故障现象：
  - 快充电流下降，BMS 显示电池温度过高或温差大。
  - MCU 温度 95℃ 车辆限扭，疑似电驱水泵故障。
  - 冬季电池升温慢，PTC 不工作或空调无热风。

## 第5页 / 第4.1章：P1E01 电池冷却水泵性能不足
- 章节 4.1 / 页码 5 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1E01
- 故障名称：电池冷却水泵性能不足
- 用户现象：用户现象：快充一段时间后电流下降，仪表提示电池温度高，诊断仪读取 P1E01。
- 触发条件：BMS 请求电池冷却水泵转速大于 50%，但实际转速低于请求 30% 持续 10 s，或电池进出水温差超过 12℃。
- 可能原因：
  1. 电池冷却水泵卡滞、供电异常或控制通讯异常。
  2. 冷却液液位低、回路有空气或冷却板堵塞。
  3. 水泵转速反馈线束接触不良。
  4. 膨胀壶盖密封失效导致系统压力不足。
- 检查步骤：
  1. 停止快充并下电，等待冷却液温度下降后检查液位，不得热态打开膨胀壶盖。
  2. 读取 BMS 电池最高温度、最低温度、进水温度、出水温度、水泵请求转速和实际转速。
  3. 执行水泵主动测试，观察膨胀壶回流；无回流时测量水泵供电 10.5V-14.5V。
  4. 检查电池冷却管路是否折弯、渗漏或夹扁，必要时抽真空加注并排气。
  5. 若实际转速反馈为 0 rpm 但水泵有工作声，检查反馈线或 LIN/CAN 通讯。
- 标准值：水泵请求与实际转速偏差 <15%；电池进出水温差 3℃-8℃；冷却液液位在 MIN-MAX；水泵供电 10.5V-14.5V。
- 维修建议：水泵卡滞时更换水泵；回路有空气时抽真空加注；管路堵塞时冲洗或更换冷却板支路；通讯异常时修复线束。
- 复核方法：快充 20 分钟，确认电池温差小于 5℃、水泵转速跟随请求、充电电流不再异常下降。
- 安全提醒：电池冷却管路贴近高压电池包，拆卸前必须高压下电；冷却液泄漏到高压连接器时按绝缘故障流程处理。

## 第6页 / 第4.2章：P0A3C 电驱冷却不足导致 MCU 95℃ 限扭
- 章节 4.2 / 页码 6 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P0A3C
- 故障名称：电驱冷却不足导致 MCU 95℃ 限扭
- 用户现象：技师提问：电机控制器温度 95℃且车辆限扭，怎么判断水泵故障？
- 触发条件：MCU IGBT 温度达到 95℃ 且电驱冷却泵请求大于 60%，车辆进入限扭模式。
- 可能原因：
  1. 电驱水泵不转或实际转速偏低。
  2. 散热器外部堵塞，风扇未启动。
  3. 电驱回路未排净空气。
  4. MCU 温度传感器偏移。
- 检查步骤：
  1. 读取热管理数据流，比较 MCU 温度、电机温度、冷却液入口温度和水泵实际转速。
  2. 执行电驱水泵主动测试，若请求 80% 而实际 0 rpm，测水泵供电和控制线。
  3. 确认风扇在高温时启动，检查散热器表面是否被泥沙堵塞。
  4. 测量 MCU 进出水管温差，完全无流量时温差异常或出水管不升温。
  5. 排气后复测，若水泵转速正常但仍过温，检查散热器和温度传感器。
- 标准值：MCU 正常 <85℃；95℃ 限扭；水泵供电 10.5V-14.5V；实际转速与请求偏差 <15%；进出水温差 3℃-10℃。
- 维修建议：供电正常但水泵不转时更换水泵；散热器堵塞时清洗；风扇不转时查风扇继电器和控制信号；温度传感器偏移时更换对应传感器或 MCU。
- 复核方法：路试 15 分钟或台架加载，确认 MCU 温度稳定低于 85℃，限扭状态解除。
- 安全提醒：高温冷却液有烫伤风险，必须降温后开盖；拆 MCU 冷却管前执行高压下电。

## 第7页 / 第4.3章：P1E02 电子水阀卡滞
- 章节 4.3 / 页码 7 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1E02
- 故障名称：电子水阀卡滞
- 用户现象：用户现象：冬季电池升温慢，空调热风不足，充电预热时间异常长。
- 触发条件：热管理控制器请求水阀开度变化超过 40%，但位置反馈变化小于 5% 持续 3 s。
- 可能原因：
  1. 电子水阀内部卡滞或齿轮损坏。
  2. 水阀位置反馈线开路或短路。
  3. 冷却液污染产生沉积物。
  4. 控制器驱动供电异常。
- 检查步骤：
  1. 读取水阀目标开度、实际开度、电池进出水温和 PTC 工作状态。
  2. 执行水阀主动测试，从 0% 到 100% 分段动作，观察实际开度是否跟随。
  3. 测量水阀供电和地线压降，供电应为 10.5V-14.5V。
  4. 检查冷却液颜色和沉积物，污染严重时检查整车冷却回路。
  5. 水阀不动作但供电控制正常时更换水阀。
- 标准值：目标与实际开度偏差 <10%；供电 10.5V-14.5V；地线压降 <0.05V；冷却液无油污和颗粒沉积。
- 维修建议：水阀卡滞时更换电子水阀并清洗管路；线束异常时修复端子；冷却液污染时按规定更换冷却液并排气。
- 复核方法：执行电池预热和空调制热，确认水阀开度跟随、出风温度和电池升温速率恢复正常。
- 安全提醒：水阀连接高压热管理部件回路，拆卸前下电并释放冷却系统压力。

- 章节 5.0 / 页码 8 / 系统：热管理系统 / 车型：NEV-A01/NEV-B02。
- 案例1：快充 8 分钟后电流从 120A 降至 20A，BMS 最高温度 47℃。P1E01 当前，水泵请求 70%、实际 0 rpm，供电正常。更换电池冷却水泵并排气后快充 25 分钟电流稳定。
