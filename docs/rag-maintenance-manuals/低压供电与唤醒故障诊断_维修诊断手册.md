## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：低压供电与唤醒系统 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：低压供电与唤醒系统 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - 12V 蓄电池和蓄电池传感器 IBS（前舱或后备箱低压电池处）
  - 低压配电盒、IG1/IG2 继电器、VCU 常电和唤醒线
  - DC/DC / 直流转换器低压输出回路
  - 网关、BMS、VCU、OBC、MCU 的低压供电和搭铁点
- 控制逻辑：低压系统负责控制器唤醒、继电器驱动、通讯网络和 DC/DC 启动。12V 静态电压 12.6V 只能说明空载电压正常，不能排除负载压降、保险虚接、搭铁不良或唤醒链路故障。
- 常见故障现象：
  - 车辆无法 READY，但 12V 静态电压为 12.6V。
  - 仪表黑屏或反复重启，多个控制器离线。
  - READY 后 12V 不升高，低压电池亏电。

## 第5页 / 第4.1章：P0562 低压系统电压低或负载压降过大
- 章节 4.1 / 页码 5 / 系统：低压供电与唤醒系统 / 车型：NEV-A01/NEV-B02
- 故障码：P0562
- 故障名称：低压系统电压低或负载压降过大
- 用户现象：用户现象：车辆偶发无法 READY，救援测 12V 为 12.6V，但按启动键仪表闪烁或重启。
- 触发条件：VCU 检测 KL30 或 IG 电压低于 10.5V 持续 500 ms，或启动 READY 时电压瞬间低于 9.5V。
- 可能原因：
  1. 12V 蓄电池内阻过大，静态 12.6V 但负载能力不足。
  2. 低压正极保险座虚接或搭铁点锈蚀。
  3. DC/DC 未启动，READY 后无法维持 12V。
  4. 休眠电流过大导致电池低电量。
- 检查步骤：
  1. 测量 12V 静态电压后继续进行负载测试，启动 READY 请求瞬间电压不得低于 9.5V。
  2. 测量蓄电池正极到 VCU KL30 的压降，负载下应小于 0.2V。
  3. 测量蓄电池负极到车身搭铁点压降，负载下应小于 0.1V。
  4. READY 成功后测量 12V 母线，正常应升至 13.5V-14.8V。
  5. 若停车后亏电，测休眠电流，休眠 30 分钟后应低于 50 mA。
- 标准值：12V 静态 12.4V-12.8V；READY 请求瞬间 ≥9.5V；负载供电压降 <0.2V；搭铁压降 <0.1V；READY 后 13.5V-14.8V。
- 维修建议：蓄电池负载不合格时更换并注册；保险座虚接时更换端子；搭铁锈蚀时清洁紧固；DC/DC 异常转入 P1C02 流程。
- 复核方法：冷车 READY 5 次，确认仪表不重启；READY 后开启大负载 10 分钟，12V 维持 13.5V 以上。
- 安全提醒：低压检查不等于高压安全，进入高压部件区域前仍需断开 MSD 并确认母线残压。

## 第6页 / 第4.2章：U3003 控制器常电或点火唤醒电源异常
- 章节 4.2 / 页码 6 / 系统：低压供电与唤醒系统 / 车型：NEV-A01/NEV-B02
- 故障码：U3003
- 故障名称：控制器常电或点火唤醒电源异常
- 用户现象：用户现象：诊断仪有时无法进入 BMS 或 VCU，仪表偶发黑屏，清码后又出现 U3003。
- 触发条件：VCU、BMS 或网关检测 KL30 常电、IG1 或唤醒线电压低于 10.5V 持续 1 s。
- 可能原因：
  1. IG 继电器触点烧蚀或继电器控制端无驱动。
  2. 低压保险虚接，控制器常电间歇中断。
  3. 车身搭铁点松动导致多个控制器复位。
  4. 网关网络管理未发送唤醒请求。
- 检查步骤：
  1. 用诊断仪读取各控制器电源模式，确认 KL30、IG1、IG2 状态是否一致。
  2. 在故障状态测量控制器插头常电和 IG 电压，不要只测蓄电池端电压。
  3. 摇动低压保险盒和主线束，观察电压和通讯是否中断。
  4. 测量 IG 继电器输出端压降，接通时触点压降应小于 0.2V。
  5. 检查网关唤醒输出和 VCU 唤醒输入是否同步变化。
- 标准值：控制器 KL30/IG 电压 10.5V-14.5V；IG 继电器触点压降 <0.2V；搭铁压降 <0.05V；唤醒线高电平通常 >9V。
- 维修建议：更换虚接保险座或 IG 继电器；修复搭铁点；唤醒线开路时按端子表修复；网关无输出时确认配置后更换网关。
- 复核方法：连续开关电 20 次并全车扫描，确认控制器均在线，无 U3003 复现。
- 安全提醒：测控制器插头时防止表笔短接相邻针脚；靠近高压控制器低压插头仍需按安全流程下电。

## 第7页 / 第4.3章：B11A0 无法 READY 的低压唤醒链路异常
- 章节 4.3 / 页码 7 / 系统：低压供电与唤醒系统 / 车型：NEV-A01/NEV-B02
- 故障码：B11A0
- 故障名称：无法 READY 的低压唤醒链路异常
- 用户现象：技师提问：车辆无法 READY，但 12V 电压 12.6V，仪表显示高压系统故障，先查什么？
- 触发条件：启动按键信号有效后，VCU 未在 2 s 内完成 BMS、MCU、DC/DC 唤醒确认。
- 可能原因：
  1. 启动按键或制动开关输入异常。
  2. VCU 唤醒输出至 BMS/MCU 支路开路。
  3. 网关未唤醒动力 CAN，导致 VCU 收不到节点确认。
  4. 12V 负载电压瞬间跌落导致节点重启。
- 检查步骤：
  1. 确认制动开关状态、挡位 P/N 状态和启动按键信号在 VCU 数据流中有效。
  2. 读取 VCU READY 条件列表，记录未满足项，不要直接更换 BMS。
  3. 测量 BMS、MCU、DC/DC 唤醒线电压，READY 请求时应从低电平变为 >9V。
  4. 检查动力 CAN 是否被唤醒，读取关键节点报文计数。
  5. 做 12V 负载压降测试，排除 12.6V 空载正常但启动瞬间跌落。
- 标准值：制动开关状态应随踏板变化；唤醒线高电平 >9V；节点应在 2 s 内在线；READY 请求瞬间 12V ≥9.5V。
- 维修建议：输入信号异常时修复制动开关或启动按键；唤醒线开路时修复线束；网关不唤醒时检查网关供电和配置；低压电池负载差时更换。
- 复核方法：冷车、热车各 READY 5 次，确认 VCU READY 条件全部满足，B11A0 不复现。
- 安全提醒：无法 READY 排查可能进入高压预充流程，操作前保持车辆驻车并远离旋转部件。
