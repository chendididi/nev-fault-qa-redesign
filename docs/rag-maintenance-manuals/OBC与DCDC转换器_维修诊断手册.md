## 第2页 / 第2章：安全要求
- 章节 2.0 / 页码 2 / 系统：OBC / DC/DC 转换器系统 / 车型：NEV-A01/NEV-B02。
- 高压断电流程：1.车辆停在绝缘工位并拉起驻车制动；2.关闭点火开关并取走钥匙；3.断开 12V 蓄电池负极；4.断开高压维修开关 MSD；5.等待 5 分钟；6.使用 CAT III 1000V 万用表测量高压母线电压，确认低于 30V；7.悬挂“禁止上电”标识。
- PPE 要求：1000V 以上绝缘手套、皮革保护手套、绝缘鞋、护目镜、绝缘垫、绝缘扳手、绝缘表笔、500V 绝缘电阻表、CAT III 1000V 万用表。
- 禁止事项：禁止高压未下电拔插橙色高压连接器；禁止短接 HVIL / 高压互锁回路强制 READY；禁止用普通试灯刺破 CAN 线或高压线；禁止在充电枪连接状态下拆卸充电口和 OBC 高压端子。
- 恢复供电前检查：确认所有高压连接器二次锁止到位，MSD 复位，冷却管路无泄漏，绝缘电阻达到交车标准，工具和人员撤离高压区域。

## 第3页 / 第3章：系统概述
- 章节 3.0 / 页码 3 / 系统：OBC / DC/DC 转换器系统 / 车型：NEV-A01/NEV-B02。
- 主要部件：
  - OBC / 车载充电机（前舱右侧，交流输入转高压直流充电）
  - DC/DC / 直流转换器（集成在 OBC 壳体或前舱高压电控支架，将高压转 12V）
  - 交流输入线束、OBC 高压输出线束和冷却水管
  - 低压蓄电池、低压熔断器盒和 VCU 充电唤醒线
- 控制逻辑：慢充时 OBC / 车载充电机根据 CP、CC 信号和 BMS 允许值输出高压直流；车辆 READY 或充电时 DC/DC / 直流转换器把高压电转换为 13.5V-14.8V 给 12V 系统供电。
- 常见故障现象：
  - 慢充枪插入后无充电电流，OBC 数据流显示交流输入异常。
  - READY 后 12V 电压仍为 12.2V 左右，仪表提示低压电源故障。
  - 慢充或 READY 一段时间后 OBC / DC/DC 过温降额或停止输出。

## 第5页 / 第4.1章：P1C01 OBC 交流输入电压异常
- 章节 4.1 / 页码 5 / 系统：OBC / DC/DC 转换器系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1C01
- 故障名称：OBC 交流输入电压异常
- 用户现象：用户现象：慢充枪已插入，仪表提示充电系统故障，OBC / 车载充电机不输出电流。
- 触发条件：OBC 检测交流输入电压低于 180V 或高于 265V 持续 2 s，且 CP / CC 显示充电枪已连接。
- 可能原因：
  1. 外部交流电源电压异常或接地不良。
  2. 慢充座交流端子松动、烧蚀或进水。
  3. OBC 交流输入保险或输入滤波电路损坏。
  4. CP / CC 状态误判导致 OBC 在无有效交流电时尝试启动。
- 检查步骤：
  1. 确认充电设备断电后检查插头和慢充座是否烧蚀，严禁带交流电拆卸慢充座。
  2. 使用万用表测量墙盒或便携充电器输出 L-N 电压，应为 198V-242V。
  3. 插枪上电后读取 OBC 数据流：交流输入电压、CP 占空比、CC 状态、OBC 允许充电状态。
  4. 断电后检查慢充座至 OBC 的交流线束连续性，L、N 线路电阻应小于 0.5 Ω。
  5. 若外部电源和线束正常，检查 OBC 输入保险和壳体进水痕迹。
- 标准值：交流输入有效范围 198V-242V（单相 220V 标称）；L/N 线束电阻 <0.5 Ω；PE 接地连续性 <0.1 Ω；OBC 壳体无进水。
- 维修建议：外部供电异常时更换合格充电设备；慢充座烧蚀时更换慢充座和端子；OBC 输入保险开路或进水时更换 OBC 总成。
- 复核方法：使用标准 220V 充电设备慢充 20 分钟，确认 OBC 输入电压、输出电流和温度稳定，无 P1C01 复现。
- 安全提醒：交流慢充输入同时涉及 AC 和高压 DC，维修前必须断开充电设备和高压维修开关，禁止带电触碰 L/N/PE 端子。

## 第6页 / 第4.2章：P1C02 DC/DC 输出电压低
- 章节 4.2 / 页码 6 / 系统：OBC / DC/DC 转换器系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1C02
- 故障名称：DC/DC 输出电压低
- 用户现象：用户现象：READY 后 12V 电压不升高，车辆偶发掉电重启，诊断仪读取 DC/DC / 直流转换器 P1C02。
- 触发条件：车辆 READY 或充电状态下，DC/DC 目标输出 14.0V，但 12V 母线电压低于 13.0V 持续 5 s。
- 可能原因：
  1. DC/DC 高压输入未建立，BMS 未闭合主继电器或高压保险开路。
  2. DC/DC 低压输出保险熔断或低压线束接触不良。
  3. 12V 蓄电池内阻过大，大负载下拉低母线。
  4. DC/DC 内部功率模块故障或过温保护。
- 检查步骤：
  1. READY 状态下用万用表测量 12V 蓄电池端电压，正常应高于 13.5V。
  2. 读取 DC/DC 数据流：高压输入电压、输出目标电压、输出电流、温度和限功率原因。
  3. 断电后检查 DC/DC 低压输出保险和蓄电池正极连接点，测量保险两端压降。
  4. 进行 12V 蓄电池负载测试，电压跌落过大时先更换蓄电池再复测 DC/DC。
  5. 若高压输入正常但无输出，检查 DC/DC 唤醒线和 CAN 通讯。
- 标准值：READY 后 12V 母线 13.5V-14.8V；低压输出保险压降 <0.1V；DC/DC 高压输入应接近电池母线电压；蓄电池负载电压不应低于 9.6V。
- 维修建议：低压保险熔断时查明短路负载后更换保险；蓄电池内阻大时更换 12V 电池；DC/DC 高压输入正常但输出低时更换 DC/DC 总成。
- 复核方法：READY 开启大灯、鼓风机和后除霜 10 分钟，确认 12V 电压保持 13.5V 以上，清码后无 P1C02。
- 安全提醒：检测 DC/DC 前先确认高压系统无绝缘故障；禁止用外接电源反向给 DC/DC 输出端加压。

## 第7页 / 第4.3章：P1C03 OBC / DC/DC 冷却不足导致过温降额
- 章节 4.3 / 页码 7 / 系统：OBC / DC/DC 转换器系统 / 车型：NEV-A01/NEV-B02
- 故障码：P1C03
- 故障名称：OBC / DC/DC 冷却不足导致过温降额
- 用户现象：用户现象：慢充开始正常，10 分钟后电流下降到 0A；READY 后低压充电电压间歇下降。
- 触发条件：OBC 或 DC/DC 功率模块温度高于 85℃ 持续 10 s，控制器降低输出功率或停止输出。
- 可能原因：
  1. 前舱电子水泵不工作或转速低。
  2. OBC 冷却回路有空气，冷却液流量不足。
  3. 散热器堵塞、冷却液液位低或水管折弯。
  4. OBC 温度传感器偏移导致误报。
- 检查步骤：
  1. 读取 OBC 和 DC/DC 温度、限功率原因、冷却泵请求转速和实际转速。
  2. 触摸前舱低压冷却管只能在断电冷却后进行，检查水管温差和液位。
  3. 使用诊断仪执行电子水泵主动测试，观察流量声音和膨胀壶回流。
  4. 排气后再次慢充 20 分钟，记录温升曲线，温度快速超过 85℃ 时检查散热器和水泵。
  5. 若温度数据突变但壳体不热，检查温度传感器数据合理性。
- 标准值：OBC / DC/DC 正常工作温度通常 <75℃；过温降额阈值约 85℃；电子水泵请求与实际转速偏差 <15%；冷却液液位在 MIN-MAX 之间。
- 维修建议：冷却液不足时查漏并补充排气；水泵不转时检查供电和 LIN/CAN 控制后更换水泵；散热器堵塞时清洗或更换。
- 复核方法：慢充 30 分钟并开启 READY 低压负载，确认 OBC/DC/DC 温度稳定低于 75℃，输出电流不再降额。
- 安全提醒：热管理回路检修前等待冷却液降温，禁止热态打开膨胀壶盖；高压部件冷却管拆卸前必须断电。
